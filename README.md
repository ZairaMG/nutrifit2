
# 🏥 Sistema de Gestión de Pacientes y Citas

## 📌 Descripción
Sistema web desarrollado para facilitar la administración de pacientes y el control de citas médicas.

## 🚀 Funcionalidades
- 🧑‍⚕️ Registro de nuevos pacientes.
- 📋 Consulta de pacientes registrados.
- 📅 Administración de citas.
- ✏️ Edición de información.
- 🗑️ Eliminación de registros.

## 🛠️ Tecnologías utilizadas
- 🐍 Python
- 🌐 Flask
- 🎨 HTML
- 💅 CSS
- 💻 JavaScript

## ⚙️ Instalación

1. Clonar el repositorio.
2. Instalar las dependencias:

   pip install -r requirements.txt

3. Ejecutar la aplicación:

   python app.py

4. Abrir en el navegador la dirección local que indique Flask.

## 👩‍💻 Proyecto
Sistema web de gestión de pacientes y citas médicas.
